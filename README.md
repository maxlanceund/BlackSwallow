  # 黑燕 (BlackSwallow)
</div>



### 1. 设计思路
抛弃一切冗余的网络与社交，做一款最纯粹的本地漫画阅读器。极致的黑白美学与底层切片渲染技术，漫画沉浸式阅读体验。

### 2.使用说明
1. **存放漫画**：将 `.zip` 或 `.cbz` 格式的漫画文件，放入手机目录的 `Download/BlackSwallow/` 文件夹中。
2. **授权扫描**：首次打开软件，请务必点击按钮，授予“所有文件访问权限”。
3. **操作与分类**：
   - **阅读**：点击封面直接阅读，点击屏幕中间可呼出极简菜单（切换无缝/连页模式、全屏状态）。
   - **分类**：长按任意一本漫画，即可为它设置分类或直接新建分类。

### 3.下载方式
前往 [Releases](https://github.com/maxlanceund/BlackSwallow/releases) 页面，下载最新的 APK 文件安装即可。
